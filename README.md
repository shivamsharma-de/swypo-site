# swypo.app

Static launch site for **swypo**, a German vocabulary app and hobby project by Shivam Sharma.

Hosted on GitHub Pages from the `main` branch (root). Custom domain: `swypo.app` (see `CNAME`).

- `index.html` — landing page
- `privacy.html` — privacy policy for this website
- `app-datenschutz.html` — privacy policy of the swypo iOS app (served at /app-datenschutz), generated from `privacypolicy.md`
- `i18n.js` — DE/EN switch: German lives in the HTML, English in this file (keys match `data-i18n`). Remembers the choice; `?lang=en` links straight to English
- `style.css`, `favicon.svg`, `icon.svg`

Support: support@swypo.app
